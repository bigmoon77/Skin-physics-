# 基本設計書 初版レビュー記録

- 対象文書: docs/basic_design.md 1.0
- レビュー結果: 初版は条件付き不合格
- 対応版: basic_design.md 1.1
- 再レビュー結果: 詳細設計へ進むための基本設計として合格。ただし数式・閾値は詳細設計で確定する。

## 1. 総評

サブシステム分割、GPU中心の処理、Soft Body / Clothの分離、共通Collision System、オフライン四面体生成の方向性は妥当だった。

一方、計算方式の候補が並ぶだけで選定方針が弱く、Gather JacobiをXPBDとして成立させる数式、双方向接触の補正配分、Spatial Hashの三角形登録と容量超過、大型要素、CCDの適用条件、アニメーション速度の入力が不足していた。このまま詳細設計へ進むと方式の前提が揃わず、後工程で大幅な設計変更が発生する可能性が高い。

## 2. 重大指摘

| ID | 重要度 | 指摘 | 1.1での対応 |
|---|---|---|---|
| BD-01 | 致命的 | Soft Body構成モデルが未選定 | Corotational FEM系を第一候補にし、力ベース・コンプライアンス制約・Shape Matching等の比較軸を明記。FEMと単純距離制約を混同しない |
| BD-02 | 致命的 | Gather Jacobiの「平均」だけではXPBDのλ更新・物理的重みが定義されない | 制約ごとのλと補正寄与出力、頂点CSR Gather、正規化・緩和の検証を明記 |
| BD-03 | 致命的 | VT / EEの接触応答が片側・双方のどちらにどう配分されるか不明 | VTは三角形重心座標、EEは線分最近接パラメータで双方の頂点へ補正を配分する方針を追加 |
| BD-04 | 致命的 | 三角形が複数セルにまたがるSpatial Hash登録、大型三角形、overflowが未定義 | 粒子と三角形の登録を分離。Swept AABB、複数セル登録、大型要素別経路、Count / Prefix Sum / Fill、再試行・エラーを追加 |
| BD-05 | 高 | CCDがSwept AABBのみで、連続Narrowphase・適用条件が不明 | VT / EE連続判定、TOIまたはSpeculative Contact、対象を速度等で絞る方針を追加 |
| BD-06 | 高 | アニメーション慣性に必要な時間履歴が不足 | 現在・前回目標位置と目標速度、不連続イベント処理を追加 |
| BD-07 | 高 | 描画頂点の四面体外対応が単純な最近傍投影候補に留まる | 境界三角形、重心座標、Rest Pose offset、誤差検査と失敗方針を追加 |
| BD-08 | 高 | Hairの表現方式が曖昧 | 初期版はHair Cards / BundlesをClothとして扱い、Strand Hairを将来拡張へ分離 |

## 3. 中程度の指摘

| ID | 指摘 | 1.1での対応 |

| BD-09 | 四面体品質が退化・反転だけでは不足 | 体積、アスペクト比、境界誤差、対応誤差を追加 |

## 4. 1.1再レビュー

### 合格と判断した点

- Soft Body / Clothの独立ソルバーと共通接触制約生成の責務が明確になった。
- Soft BodyはCorotational FEM系を第一候補とし、FEMとXPBDを安易に同一視しない方針が明確になった。
- Gather方式は制約ごとのλ更新と頂点CSR Gatherを前提にし、単純平均をXPBDと呼ばないことが明記された。
- VT / EE双方の頂点への補正配分方針が示された。
- Spatial Hashの三角形複数セル登録、大型要素経路、Hash値と実セル座標の照合、overflow検出・再試行方針が追加された。
- CCDをBroadphaseと連続Narrowphaseに分け、全候補へ一律適用しない方針が示された。
- アニメーション速度、不連続イベント、Render Binding誤差、初期貫通上限が明記された。
- Hair Cards / BundlesとStrand Hairの範囲が分離された。

### 詳細設計で必ず解決する残課題

1. Corotational FEMを採用する場合の具体的な構成式、積分法、安定化手法。コンプライアンス制約方式と力ベース方式の比較。
2. XPBD λ更新式、Jacobi補正の正規化、緩和係数、収束性の検証。
3. VT / EE接触の重み、摩擦、反発、λの寿命と重複接触排除。
4. Spatial Hashのセルサイズ、巨大要素処理の具体方式、メモリ上限と再試行回数。
5. CCDの退化ケース、TOI計算またはSpeculative Contactの具体式。
6. Rest Pose offsetの座標系と、変形時にどのように追従させるか。
7. GTX 1660 SUPER上での実測に基づく数値受け入れ基準。

これらは実装方式を左右する重要事項だが、基本設計で方針と責務が定義されたため、詳細設計で数式・データレイアウト・閾値として確定できる。

## 5. 最終判定

**basic_design.md 1.1は詳細設計へ進むための基本設計として合格。**

ただし、Soft Body構成モデルの最終採用は詳細設計で比較試験条件と判断基準を定義した後に確定する。性能・精度の数値を実測なしに保証しないこと。
